# Gerenciador de Finanças Pessoais

Programa de terminal em Python para controlar receitas e despesas. 
Projeto de estudo feito para praticar funções, listas, dicionários e leitura e escrita de arquivos JSON.

# Funcionalidades

- Cadastro de receitas e despesas com valor, categoria, descrição e data automática
- Listagem de todas as movimentações
- Cálculo do saldo (receitas, despesas e total)
- Total de gastos por categoria
- Dados salvos em arquivo JSON, sem perder nada ao fechar o programa

# Como rodar

1. Instale o [Python 3](https://www.python.org/downloads/).
2. Baixe o projeto em **Code → Download ZIP** e extraia a pasta.
3. Abra a pasta no VS Code.
4. No terminal, execute:

```
python main.py
```

# Exemplo

```
=== Gerenciador de Finanças ===
1 - Adicionar movimentação
2 - Listar movimentações
3 - Ver saldo
4 - Ver total por categoria
0 - Sair
```
